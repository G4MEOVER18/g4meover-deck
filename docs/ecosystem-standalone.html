Roadmap zum nahtlosen Ökosystem

Security Suite + Pentest-Cockpit vereint auf dem Deck. Phasen A–E.

Phase A

WiFi-Kette schließen

  • ✓ WROOM-Relay · Heltec-RX · Flipper-UART-TX · Pi-ukfe_rf
  • ▹ LilyGo T-Dongle S3: ESP-NOW-RX-Firmware (nächster Bau)
  • ▹ Flipper→WROOM am realen Devboard verdrahten + NET-Ping live
  • ▹ Rückkanal Satellit → Flipper/Pi (ACK/Status)
Phase B

Deck-Gehirn scharf schalten

  • ▹ Pi 4 mit SD provisionieren (install.sh) + UART↔WROOM
  • ▹ deck-daemon härten (Auth, Geräte-Discovery, Persistenz)
  • ▹ Flipper-USB-RPC-Modul im Cockpit
Phase C

UI vereinen — alles an einem Punkt

  • ▹ Cockpit-Seite „Ökosystem": Live-Board + Aktions-Router + Funk-Karte
  • ▹ Security-Suite-Tab (Blue-Team) + Hashcat-Backend
  • ▹ Web-Dashboard (Handy) auf deck-daemon
Phase D

Funk-Breite

  • ▹ ESP-Firmwares G4MEOVER-branden (Marauder/GhostESP) + ukfe_rf-RX
  • ▹ Heltec LoRa-Langstrecke (dual FSK/LoRa) · Zigbee-Kette · Wardriving-Rig
Phase E

Innovation & Stabilität

  • ▹ Auto-Transport-Failover (868 → ESP-NOW → USB, Counter macht's sicher)
  • ▹ „One-Tap-Attack": Flipper captured → Pi cracked → Heltec meldet per LoRa
  • ▹ Ein Capture-Pool (Vault ↔ Pi-DB) · CI + App-Härtung · Pairing statt Hardcode-Secret
